# 오늘할일

개인용 안드로이드 할 일 체크리스트 앱입니다. 로그인과 인터넷 연결 없이 기기 내부에 할 일을 저장합니다.

## 현재 기능

- 할 일 추가
- 완료 체크 및 취소
- 할 일 삭제
- 전체 / 진행 중 / 완료 필터
- 앱을 종료해도 목록 유지

## 실행 방법

1. Android Studio에서 `TodayTodo` 폴더를 엽니다.
2. 프로젝트 동기화가 끝날 때까지 기다립니다.
3. 안드로이드 휴대폰의 개발자 옵션과 USB 디버깅을 켜거나 에뮬레이터를 실행합니다.
4. 상단의 Run 버튼을 누릅니다.

프로젝트는 JDK 17, Android SDK 35를 기준으로 작성되었습니다. Android Studio가 권장하는 Gradle Wrapper 생성 안내가 나타나면 그대로 생성하면 됩니다.

## 주요 코드

화면, 상태 관리, 기기 저장 로직은 `app/src/main/java/com/example/todaytodo/MainActivity.kt`에 있습니다.

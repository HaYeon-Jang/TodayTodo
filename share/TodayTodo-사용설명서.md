# TodayTodo 사용 설명서

TodayTodo는 날짜별 할 일을 기록하고 완료 여부를 관리하는 개인용 체크리스트 앱입니다.

## 1. 앱 설치

1. `TodayTodo.apk` 파일을 휴대폰으로 다운로드합니다.
2. 다운로드한 파일을 엽니다.
3. 설치가 차단되면 안내에 따라 해당 브라우저 또는 파일 앱의 **출처를 알 수 없는 앱 설치**를 허용합니다.
4. **설치**를 누릅니다.

기존 TodayTodo가 설치되어 있다면 새 APK를 실행해 업데이트할 수 있으며, 같은 서명의 앱인 경우 기존 할 일과 설정이 유지됩니다.

## 2. 날짜별 할 일 관리

- 화면의 **이전**, **다음** 버튼으로 날짜를 하루씩 이동할 수 있습니다.
- 가운데 날짜 버튼을 누르면 달력에서 과거 또는 미래 날짜를 직접 선택할 수 있습니다.
- 다른 날짜를 보고 있을 때 **오늘로 돌아가기**를 누르면 오늘 날짜로 이동합니다.
- 입력란에 할 일을 작성한 후 **추가**를 누르면 현재 선택한 날짜에 등록됩니다.
- 체크박스를 누르면 완료 상태로 변경됩니다.
- **전체**, **진행 중**, **완료** 필터로 항목을 구분해서 볼 수 있습니다.

## 3. 할 일 삭제

항목 오른쪽의 **삭제**를 누르면 확인창이 표시됩니다. 확인창에서 삭제를 한 번 더 눌러야 실제로 삭제됩니다.

반복 일정으로 만든 항목은 다음 중 하나를 선택할 수 있습니다.

- **이 일정만 삭제**: 선택한 날짜의 항목만 삭제합니다.
- **전체 삭제**: 같은 반복 일정으로 생성된 모든 날짜의 항목을 한 번에 삭제합니다.

## 4. 오후 11시 미완료 알림

- 당일 오후 11시에 완료하지 않은 할 일이 있으면 알림이 표시됩니다.
- 알림에는 미완료 개수와 할 일 제목이 최대 3개까지 표시됩니다.
- 알림을 누르면 TodayTodo가 열립니다.
- 최초 실행 시 알림 권한 요청이 표시되면 **허용**을 선택해야 합니다.
- 휴대폰의 배터리 절전 상태에 따라 알림이 몇 분 정도 늦어질 수 있습니다.

## 5. 디데이 설정

1. 오른쪽 위 **⋮** 메뉴를 누릅니다.
2. **디데이 설정**을 선택합니다.
3. **새 디데이 추가**를 누릅니다.
4. 이름과 날짜를 입력한 후 **저장**을 누릅니다.

디데이는 최대 2개까지 설정할 수 있습니다. 등록된 디데이를 다시 누르면 수정하거나 삭제할 수 있습니다.

- 미래 날짜: `D-10`
- 오늘: `D-DAY`
- 지난 날짜: `D+3`

설정한 디데이는 홈 화면 상단의 작은 KPI 카드로 표시됩니다.

## 6. 반복 일정 등록

1. 오른쪽 위 **⋮** 메뉴를 누릅니다.
2. **반복 일정 등록**을 선택합니다.
3. 할 일 제목을 입력합니다.
4. 반복 방식을 선택합니다.
5. 시작일과 종료일을 지정한 후 **등록**을 누릅니다.

지원하는 반복 방식은 다음과 같습니다.

- **매일**: 시작일부터 종료일까지 매일 등록
- **매주**: 선택한 요일마다 등록, 여러 요일 선택 가능
- **매월**: 시작일과 같은 날짜에 매월 등록

매월 반복에서 해당 날짜가 없는 달은 그 달의 마지막 날로 자동 조정됩니다. 예를 들어 31일 반복은 2월에 2월의 마지막 날로 등록됩니다.

## 7. 백업 파일 저장

1. 오른쪽 위 **⋮** 메뉴를 누릅니다.
2. **백업 파일 저장**을 선택합니다.
3. 저장 위치와 파일명을 선택합니다.

휴대폰을 바꿀 경우를 대비해 Google Drive에 저장하는 것을 권장합니다. 백업 파일에는 다음 정보가 포함됩니다.

- 모든 날짜의 할 일
- 완료 여부
- 반복 일정으로 생성된 항목
- 디데이 설정

## 8. 백업 파일 복원

1. 오른쪽 위 **⋮** 메뉴를 누릅니다.
2. **백업 파일 복원**을 선택합니다.
3. TodayTodo 백업 JSON 파일을 선택합니다.

백업 항목은 현재 항목과 합쳐집니다. 같은 항목을 여러 번 복원해도 중복으로 추가되지 않습니다. 백업에 디데이가 있으면 디데이 설정도 함께 복원됩니다.

## 9. 다른 사람에게 공유하기

`TodayTodo.apk`를 Google Drive에 올린 후 공유 설정을 **링크가 있는 모든 사용자 → 뷰어**로 변경하고 링크를 전달하면 됩니다.

설치 파일과 설명서:

- `TodayTodo.apk`
- `TodayTodo-사용설명서.md`
